## 新增功能

- 新增圆形、椭圆框选。拖动前可选择选区形状，也可在工具栏头部切换；圆形始终保持等宽等高。导出 PNG 保留透明边角。
- 新增图钉按钮，按 F 或点击图钉，将当前截图连同标注暂存在屏幕顶层。
- 图钉形成时，截图从选区位置平滑收拢为悬浮图片，配合淡入过渡；系统启用减少动态效果时直接呈现。
- 图钉支持拖动、滚轮缩放、复制原尺寸图片和关闭；Esc、右键或关闭按钮可移除当前图钉。
- 可同时暂存多张图片。暂存内容仅在内存中保留，关闭图钉或退出程序即释放，不保存历史。
- 图钉操作不改变剪贴板；仍可用对号或 Enter 直接复制截图。
- 保留紧凑毛玻璃工具栏、模糊／马赛克画笔、默认开机启动及跟随系统主题。
