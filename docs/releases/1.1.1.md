## 修复与改进

- 修复升级安装时勾选自动退出后仍需手动关闭应用的问题。安装前会识别当前会话中从旧安装目录或便携目录运行的定格T，先请求正常退出，未响应的旧版则结束已核验的进程，确认退出后才安装。
- 安装选项新增默认勾选的“安装前自动退出正在运行的定格T”。取消勾选时保留运行实例并阻止安装。
- 圆形、椭圆改为图形标注；截图选区始终保持矩形。
- 在图形标注组切换方框、圆形、椭圆，共用颜色、粗细滑块、撤销／重做和局部擦除。快捷键 O / L 分别选择圆形／椭圆标注。
- 保留图钉暂存及过渡动画，暂存图片包含完整的矩形截图。

## 下载与升级

- `ScreenClip-1.1.1-Windows-x64-Setup.exe`：Windows 64 位安装版，升级时保持勾选自动退出即可。
- `ScreenClip-1.1.1-Windows-x64-Portable.zip`：Windows 64 位便携版，完整解压后运行 `screen_clip_win.exe`。手动替换便携版文件前请先退出旧实例。
- `SHA256SUMS-1.1.1.txt`：下载文件的 SHA-256 校验值。

本次仅提供 Windows 软件包，macOS 尚未完成真机编译验收。
