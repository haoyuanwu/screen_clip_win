## 软件介绍

定格T 是一款轻巧的常驻截图工具。启动后驻留系统托盘，没有主页，也不保存截图历史。按 Ctrl + Shift + X 唤起截图，框选后直接完成标注，按 Enter 或点击对号即可复制到剪贴板，随时粘贴到聊天和文档中。

## 本版功能

- 默认开机启动，登录后驻留托盘；可在偏好设置中关闭，保留关闭选择。
- 支持区域、窗口和全屏截图，以及 0 / 3 / 5 / 10 秒延时。
- 在确认截图前完成箭头、方框、画笔、文字和序号标注。
- 单个隐私画笔图标切换模糊与马赛克，支持连续涂抹、调整粗细、局部擦除和撤销／重做。
- 文字输入框随内容伸缩，支持颜色、背景、字号、粗体、斜体和下划线。
- 紧凑毛玻璃工具栏，自动避开显示器四边，提供画笔圆圈预览与动画反馈。
- 支持跟随系统、浅色和深色主题。
- 默认复制图片；仅主动保存时输出 PNG，不保存截图记录。

## 下载与使用

- `ScreenClip-1.0.0-Windows-x64-Setup.exe`：Windows 64 位安装版，运行后按向导安装，支持卸载。
- `ScreenClip-1.0.0-Windows-x64-Portable.zip`：Windows 64 位便携版，完整解压后运行 `screen_clip_win.exe`，请勿直接在压缩包内运行。
- 安装或解压后启动一次即可默认注册开机启动。便携版应放在固定目录，避免移动后启动路径失效。
- 启动后没有主窗口，请从托盘图标或 Ctrl + Shift + X 进入。升级前请先从托盘退出旧版本。
- 当前发布 Windows 安装包；macOS 版本尚未完成真机编译验收，本次不提供 macOS 安装包。
