# 定格T 1.1.4

## 更新

- macOS 开机启动显示“已关闭”时，点击会尝试启用并自动打开系统“登录项”设置，方便确认或允许。
- “待系统允许”状态也支持点击进入登录项设置。
- 首次运行继续默认启用开机启动，不自动弹出设置；保留用户主动关闭的选择。
- 保留 1.1.3 的屏幕录制授权恢复提示与“定位当前应用”入口。

- macOS 钥匙串服务名和显示名改为“定格T”，已有翻译安全配置会迁移；首次迁移访问旧条目时可能仍出现一次旧名称授权提示。迁移失败不覆盖旧配置。

## 验证

- 49 项相关自动测试通过，覆盖自启动入口、钥匙串迁移、拒绝授权与翻译流程。

## 下载与安装

- Apple Silicon 下载 arm64.dmg；Intel 下载 x64.dmg。要求 macOS 14 或以上。
- 退出旧版后，打开 DMG 并将“定格T.app”拖入 Applications。
- 使用本地临时签名，尚未经 Developer ID 签名及 Apple 公证。升级后若屏幕录制开关已开启但仍被拒绝，请移除旧授权条目、添加当前应用并重新授权，再完整退出并重开。
- 本次发布 macOS 两种架构的安装包及 SHA-256 校验文件；Windows 用户继续使用 1.1.3。
- Intel 安装包在 Apple Silicon 上构建并检查架构，未在 Intel 实机验收。
