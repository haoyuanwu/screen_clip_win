## 多渠道翻译

- 新增独立文字翻译、截图选区 OCR 翻译与翻译渠道设置。
- 支持六种预置服务及自定义兼容接口，Key 存入系统安全存储。
- 支持十种源语言选项、九种目标语言、取消、重试、复制与耗时/token 反馈。
- 原文和译文仅保留当前内存状态，无自动翻译和历史保存。

- 选区翻译改为 OCR 扫描反馈与图上译文：按文字区域生成浅米色背景的可编辑标注，支持导出和整批撤销；未配置 Key 自动打开渠道设置。

- 修复 macOS 智能窗口选区在 Retina / 混合缩放显示器上出现小尺寸窗口画面的问题：独立窗口抓取显式按目标像素尺寸缩放填充。

- 新增翻译“对照阅读”：隐藏图上译文并在选框附近显示译文窗口，悬停原文段落同步定位和背景高亮，支持段落切换与复制全部译文。

- 提升截图工具栏和图标对比度，按功能重排二级控制；对照翻译窗口以 8px 间距随选框自动选择左右或上下位置。
- 翻译配置支持验证 API Key、地址和模型；截图中配置时保留选区及标注，保存后继续操作。

- 对照译文窗口支持拖动标题移动，显示层级高于工具栏并按实际尺寸避让；小选区或译文字号过小时自动启用对照阅读。

- 截图工具栏定位预留二级菜单展开空间并保持停靠锚点，上方停靠时菜单向上展开，避免开关菜单时主工具栏跳位。

- 工具栏支持拖动顶部尺寸/三横线区域移动，保留手动位置并限制在当前屏幕内。


## Windows 同步与修复

- Windows 固定颜色窗口移除外围背景与留白，窗口高度跟随卡片内容，圆角外直接显示桌面。

- 修复 Windows 中文输入法拦截截图／取色 WASD 与 Esc：非文字操作在系统分发前还原被 IME 转换的原始快捷键，文字标注保留系统组合输入。
- 截图首帧后主动把 Flutter 焦点从常驻工具条转入编辑器，并在窗口重新激活时校正原生焦点与输入模式。
- 智能选区遇到无权置顶的窗口时保留当前冻结画面与矩形选区，不再报置顶错误或抢走键盘焦点。

- Windows 本地同步 macOS v1.1.2：OCR、二维码、取色器、图钉文字选择及共享标注交互。
- 修复 Windows OCR 插件编译、图钉 OCR 解析、减少动画尺寸与显示器 DPI。
- 增加无 PNG 编解码的取色路径和完整插件依赖打包脚本。
