# 定格 1.3.0

- 新增 macOS 选区录屏。框选后可选择 MP4 或 MOV、30／60／120 fps 目标帧率及启动延时。录制时从菜单栏的红色按钮停止，旁边显示时长。视频默认保存到桌面，可在偏好设置更改目录，保存后会在 Finder 中选中视频。
- 截图工具栏、设置、录屏、长截图、取色和翻译统一为扁平界面。实色面板使用细边和阴影，按钮居中对齐，交互动效遵循系统的减少动态效果设置。
- 截图工具栏避让 Dock 和菜单栏。减少框选时的重复绘制，马赛克纹理在使用时生成。macOS 取色改为吸管光标，尖端对应采样像素。
- 本地翻译语言包可以在后台下载，下载期间可返回或关闭设置。操作错误以可关闭、可复制的悬浮通知显示。

此版本提供 macOS 14.0 及以上的 Apple Silicon（arm64）安装包。
