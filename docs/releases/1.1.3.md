# 定格T 1.1.3

## 翻译

- 新增 Argos 本地中英翻译，按需下载语言包，无需 Key。macOS 开发与发布构建均包含独立引擎及 HTTPS 根证书。
- 缺少语言包时直接提示下载，下载在应用后台继续，支持进度、取消与重试；关闭翻译面板不会中断下载。
- 工具栏点击翻译直接执行，切换或交换语言自动重译；取消只停止任务，保留语言工具栏。
- OCR 按行距、对齐和字号保守合并段落，区分列表、短标签及多栏文字。
- 图上译文改为只读覆盖层，去掉彩色底板；采样背景覆盖原文行，参考原文字号和颜色绘制译文，并扩展、避让以减少重叠。照片、渐变和纹理背景仍可能留下还原痕迹。
- 保留对照阅读、段落定位、复制和撤销；在线渠道默认关闭，已有配置保留。
- 移除腾讯云 TMT 专属渠道。

## 下载与安装

- Apple Silicon：arm64.dmg；Intel Mac：x64.dmg，要求 macOS 14 或以上。
- 退出旧版后打开 DMG，将“定格T.app”拖入 Applications。首次截图需屏幕录制权限。
- 安装包使用本地临时签名，尚未经 Developer ID 签名及 Apple 公证。
- Windows x64：下载 `ScreenClip-1.1.3-Windows-x64-Setup.exe`，退出旧版后运行安装程序覆盖更新。内含独立本地翻译引擎与 HTTPS 根证书，无需安装 Python。
- 语言包需首次联网下载，之后中英翻译可离线使用。
