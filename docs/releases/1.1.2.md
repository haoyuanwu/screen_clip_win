# 定格T 1.1.2

本次分别发布 macOS Apple Silicon（arm64）和 Intel（x64）DMG，要求 macOS 14.0 及以上。

- `ScreenClip-1.1.2-macOS-arm64.dmg`：Apple Silicon（M 系列）。
- `ScreenClip-1.1.2-macOS-x64.dmg`：Intel。
- `SHA256SUMS-1.1.2-macOS.txt`：两个安装包的 SHA-256 校验值。

两个安装包中的应用、Flutter 引擎、插件与原生库均只包含对应架构。

## 更新

- 多屏截图和取色在各显示器原位显示快照，支持独立桌面空间、不同缩放比例及跨屏拖动。
- 智能窗口备选和取色预览实时跟随鼠标；点击桌面只选择鼠标所在显示器，手动拖动仍支持跨屏。
- 全局取色使用原始 sRGB 像素通道，跳过重复 PNG 编解码和马赛克准备；移动时仅同步卡片区域，目标刷新间隔 16 毫秒。
- 固定取色面板去掉外层背景和阴影，色值可点击复制；实时卡片不会拦截采样鼠标。
- 截图顶部操作提示仅在主屏顶部居中显示。
- 修正首帧显示、隐藏窗口暂停刷新、权限误判以及重复实例与调试重跑冲突。
- 保留 OCR 图片文字选择、图钉自动 OCR、二维码扫描、文字与图形标注等功能。

## 安装

1. 退出正在运行的定格T。
2. 打开 DMG，将“定格T.app”拖入 Applications 后启动。
3. 应用常驻菜单栏。`Control + Shift + X` 截图，`Control + Shift + C` 取色。
4. 首次使用按系统提示允许屏幕录制；权限变更后可退出并重新启动。

此包使用本地临时签名，尚未经过 Apple Developer ID 签名和公证。macOS 可能阻止首次打开，需要在“系统设置 → 隐私与安全性”中确认打开。

## 验证范围

- 83 项 Flutter 自动测试、静态检查及 macOS Release 构建。
- Apple Silicon 本机双屏截图、取色、智能选窗和调试启动检查。
- Intel 运行尚未真机验收；Windows 本次未生成新安装包，请使用 v1.1.1。

下载后可使用同一 Release 中的 SHA-256 校验文件核对 DMG。
