# Windows 同步 macOS v1.1.3

当前源码基于远端 `2c5d153`（macOS v1.1.3）。本次对齐保持 1.1.3 版本号，Windows 安装包补充至现有 GitHub Release。

## 1.1.3 对齐

- 共享代码同步后台语言包下载、进度／取消／重试、关闭翻译面板不中断下载、语言交换自动重译。
- 同步 OCR 段落合并、只读图上译文、原文背景采样恢复、字号颜色参考、译文扩展与避让、对照阅读。
- Windows `flutter run` / `flutter build windows` 自动嵌入本地引擎及 HTTPS 根证书，与 macOS 构建行为一致。按源码输入时间缓存辅助进程，首次需要 Python 与联网安装固定依赖；最终用户不需 Python。
- Windows 安装脚本默认版本与源码统一为 1.1.3；打包脚本复用同一缓存嵌入流程。
- 静态检查、144 项 Flutter 测试（另有 2 项原有平台跳过）、Windows Release 构建，以及最新打包引擎真实中英互译、OCR 分段和取消验收通过。
- 保留平台合理差异：Windows 原生截图／输入法／系统 OCR，macOS 使用自身截图与沙盒签名机制。不将 macOS 原生接口直接移植到 Windows。


## 同步范围

- OCR：选区离线识别、扫描反馈、跨行文字选择与复制。Windows 使用本地 desktop_vision 插件及系统 OCR 组件。
- 二维码：原生 ZXing 库本地解码多码，保留标记、内容查看与浏览器打开交互。
- 取色：Ctrl+Shift+C 全局取色、I 进入选区取色，像素放大、HEX／RGB、固定桌面卡片；Windows 直接传递 RGBA 像素，跳过 PNG 编解码。
- 标注：两点或拖动直线、形状说明气泡、忽略微小误触、文字自适应与样式、隐私画笔／矩形处理、WASD 光标微调。
- 图钉：悬停毛玻璃工具栏、自动 OCR、文字拖选／全选／复制、图片复制、Alt 拖动、滚轮缩放、淡入及减少动画支持。
- 多屏：保持 Windows 原生虚拟桌面框选，主屏优先排列、选区和工具栏坐标使用源像素；图钉工具栏按所在显示器 DPI 更新。
- 窗口截图：Windows 延续临时置顶、完成或取消后恢复的实现；macOS 独立窗口快照属于平台实现差异。

## 修复的 Windows 阻塞

- OCR 插件按 UTF-8 编译，并使用标准 C++20 协程与完整 WinRT 集合头文件。
- 修复 MSVC 无法编译的图钉 OCR 数据遍历表达式。
- 图钉关闭动画时不再被窗口创建阶段的 WM_MOVE 覆盖为错误尺寸。
- 本地打包脚本从 pubspec.yaml 读取版本，检查 OCR、二维码和文件选择插件，附带 Visual C++ 运行库并生成校验值。

## 验证

共享 Flutter 回归测试、Windows Release 构建、真实 Windows OCR 内存图片识别、图钉文字复制与过期结果保护、原生 ZXing 多二维码解码、截图确认复制、图钉置顶／缩放／关闭、全局取色固定卡片均已检查。

跨屏负坐标、上下排列与混合缩放的编辑逻辑有合成布局测试；未宣称所有物理显示器组合均已真机验收。

Windows OCR 识别语言取决于系统已安装的 OCR 语言组件；缺少所需语言时需在系统语言设置中安装。

## 原生验证入口

- `tools/qr_native_smoke_test.dart`：在当前平台真实加载 ZXing。
- `tools/windows_native_tests`：CMake 控制台测试，合成图片识别与图钉文字交互，不读取用户文件。
- `tools/smoke_windows.ps1`：仅操作测试实例的窗口，验证截图、图钉及取色；会更改剪贴板，结束后恢复测试前光标位置。

## 输入与智能选区修复

截图首帧就绪时显式切换编辑器焦点。Windows 非文字操作阶段暂时解除 Flutter 视图的输入法上下文关联，并在进入文字编辑或退出截图时恢复；仍在队列中的 VK_PROCESSKEY 在 TranslateMessage 之前恢复原始按键。文字编辑期间保留系统组合输入。遇到高权限或受保护窗口不能临时置顶时，继续使用原冻结画面中的矩形选区，不宣称该降级画面包含被遮挡内容。

`tools/test_windows_keyboard.ps1` 使用系统 SendInput 检查实际 WASD 四方向微调与 Esc 取消。发送任何按键之前都检查测试实例是否拥有前台；其他窗口抢占焦点时停止，避免向其他程序发送按键。
