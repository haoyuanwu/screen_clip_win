# 定格T ScreenClip 产品与架构

用户定位为需要快速截屏沟通的 Windows、macOS 桌面用户。最终约束：无主页、无记录、默认剪贴板；所有标注发生在截屏覆盖层中，在确认生成最终图片之前完成。

## 核心交互

1. 应用启动后隐藏窗口，驻留托盘或菜单栏。
2. 全局快捷键或原生菜单触发屏幕冻结。底图仅保存在内存，用作选区与标注预览。
3. 区域模式拖动框选；窗口模式悬停高亮后点击；全屏模式直接预选全屏。
4. 在同一个覆盖层内移动、调整选区，添加箭头、矩形、画笔、文字、序号或局部模糊画笔。支持撤销／重做。
5. Enter / 复制：裁切选区、合成标注，生成原像素 PNG，写入系统图片剪贴板，释放当前会话并隐藏覆盖层。
6. 保存：调用原生保存对话框；成功后释放会话。取消保存则留在原选区。
7. Esc / 右键：放弃当前会话，保持原剪贴板内容。

只有主动保存才写入图片文件。不创建历史列表、缩略图、截图索引、自动保存目录、云端副本或崩溃恢复截图。偏好文件仅包含 appearance 和 delay。

## 共享架构

- lib/main.dart：应用生命周期与主题切换。
- lib/src/theme.dart：共享主题与颜色语义。
- lib/src/controller.dart：单次截屏会话、延时状态、偏好设置、平台调用和结束清理。
- lib/src/platform_bridge.dart：显式 MethodChannel 边界，返回内存 PNG 与窗口矩形。
- lib/src/workspace.dart：按需工具条、偏好设置与全屏会话宿主；无首页路由。
- lib/src/editor.dart：覆盖层选区、像素放大镜、调整点、就地标注、撤销历史与 PNG 合成。标注坐标始终使用源图像素，不依赖逻辑 DPI。
- windows/runner/desktop_bridge.h：托盘、RegisterHotKey、GDI 冻结虚拟桌面、窗口边界、无边框覆盖层、保存对话框、PNG 与位图剪贴板。
- macos/Runner/MainFlutterWindow.swift：菜单栏、Carbon 全局快捷键、ScreenCaptureKit、无边框覆盖层、图片剪贴板与 NSSavePanel。

状态流转为：常驻 →（可选倒计时）→ 冻结底图 → 框选与标注 → 确认生成 → 复制／保存 → 常驻。取消从倒计时或覆盖层返回常驻；输出失败保留会话并允许重试。

Flutter 只依赖 SDK；没有另加截图、窗口、数据库或云服务插件。单一会话用 ChangeNotifier 驱动，同一控制器注入可替换的平台桥，便于验证取消与失败恢复。

## 平台适配

Windows 与 macOS 均覆盖全部显示器的桌面联合范围，支持跨屏选区、负坐标及上下错位排列。macOS 按最高显示器像素比例合成桌面，智能窗口与图钉使用统一桌面坐标。工具栏仍约束在单块显示器内。macOS 使用各显示器独立覆盖层，原位显示对应快照，避免独立桌面空间裁掉跨屏窗口；全部显示器按各自分辨率裁取同一 Flutter 编辑层，交互时最高 30fps 更新，静止时不循环重绘。所有覆盖层共用一个指针流程，跨屏拖动连续。原生快照先显示以唤醒隐藏的 Flutter 窗口，解码后的编辑首帧通过尺寸校验后接替；抓取时排除本应用窗口。Windows 隐藏后等待桌面合成刷新再抓取，完成 Flutter 首帧后显示。macOS 最低 14.0，保留 App Sandbox，导出仅通过用户选定文件的读写授权。

窗口模式选取冻结画面上的可见窗口区域，不重建遮挡内容。macOS 需要屏幕录制权限；DRM 或系统保护内容由操作系统决定能否捕获。

## 验证

自动化检查覆盖原像素裁剪与局部模糊、内存会话释放、不产生截图文件、保存取消与剪贴板失败恢复、确认前不复制，以及同一覆盖层的框选、标注、键盘撤销和确认。

Windows 原生冒烟脚本验证隐藏启动、真实原生冻结、200% DPI 对应源像素输出、确认前剪贴板不变、Enter 复制并隐藏、Esc 取消且保持剪贴板。macOS 尚需 Mac / Xcode 真机编译与系统权限验收。

文字在选区内直接输入，输入框随内容和换行伸缩；点击已有文字可再次编辑，支持字号、颜色、加粗、斜体和下划线。输入文字时 Enter 换行，Ctrl / Command + Enter 完成文字；选区确认仍默认复制到剪贴板。工具栏上限宽度收窄至 480 逻辑像素，箭头和矩形线条加粗。

## 自定义工具条与图层更新

- 产品内按钮、色板、滑块、延时选项和外观选项均使用共享自定义 Flutter 控件，不使用系统菜单、Material 下拉框或样式弹窗。系统托盘、屏幕权限与文件保存对话框属于操作系统集成。
- 按 Apple HIG 的工具条分组、材质与实时反馈原则设计：中性表面、系统蓝主操作、克制阴影、16px 圆角、焦点提示、键盘可达与减少动画支持。参考 [Apple Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[Sliders](https://developer.apple.com/design/human-interface-guidelines/sliders)、[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。
- 文字编辑框与输出共享 10 源像素内边距，支持文字色、透明或实色背景、粗体、斜体、下划线和字号。字号与线条粗细采用自绘滑块；文字可点击继续编辑。
- 工具条高度按实际内容测量，在选区上下自动放置，最大高度约束内可滚动；色板在工具条内展开，不另开菜单。
- 固定图层：屏幕底图 → 局部模糊 → 自由画笔 → 文字／箭头／方框／序号。相同前景层按创建顺序绘制；模糊无论何时添加都不会抹去前景标注。
- 模糊是视觉处理，不等同于彻底删除敏感信息；不宣称可保证信息无法推断。
- 本次通过 UI-UX-Pro-Max 技能与 Apple HIG 完成界面设计。Product Design 已连接，本次依其框架做桌面组件复核；结果及证据限制见 docs/product-design-review.md。

紧凑交互更新：工具栏宽度从 640 缩至 480 逻辑像素，上下内边距压缩为 4–6px，头部提示与操作合并收紧；字号滑块与字形选项同排，色板仅在需要时展开。按钮支持约 110ms 的按压缩放回弹、100ms 的悬停／选中底色过渡，设置页切换约 170ms，工具状态与色板展开淡入并自动调整高度，工具条约 140ms 入场，位置采用同帧边界约束。屏幕底图本身不参与页面切换动画。遵循系统减少动态效果设置；减少动画时状态直接切换。

毛玻璃与笔刷反馈：浮层使用 24px 背景模糊，浅色 72%、深色 70% 的中性半透明底色（高对比度模式恢复实色）。自由画笔、箭头、矩形、模糊画笔和序号工具在选区内以同色圆圈表示当前宽度，源像素映射到显示坐标；模糊光标直径对应实际涂抹范围。工具条粗细滑块旁有同色圆圈预览，大笔刷在工具条内缩小显示并保留实际像素数值。圆圈只属于编辑反馈，不进入导出；离开选区、进入工具条或编辑文字时隐藏。

橡皮擦更新：模糊画笔和橡皮擦光标固定使用白色空心圆，移除所有画笔圆圈的中心点。按 E / 工具栏“橡皮擦”进入擦除状态，拖动会按圆形范围局部移除此前的画笔、箭头、方框、文字、序号和模糊笔画，恢复原始画面；不修改原图。擦除宽度使用滑块实时调整，单次擦除可撤销／重做；后续绘制不受此前擦除遮罩影响。预览与 PNG 导出共用按时间顺序的分层擦除合成逻辑。

四边定位更新：原生层返回每块显示器在截图中的实际像素边界；工具栏选择与选区重叠面积最大的单块显示器，不使用整片虚拟桌面作为安全区域。每次布局直接测量当下内容尺寸，依次寻找选区下、上、右、左的可用位置；放不下时覆盖选区的一部分，但保持尺寸并约束在当前显示器内。选区靠边仅重新定位，宽高约束与距离屏幕边缘无关。取消了可能跨越屏幕边界的位置补间动画，保留面板内容与按钮动画。自动化检查覆盖两块屏幕各四角、文字与色板展开的中间帧，以及竖屏和上下错位显示器布局。

主题提供“跟随系统 / 浅色 / 深色”三种选择。新安装默认跟随系统，系统明暗变化即时生效；已有用户的手动明暗选择继续保留。主题偏好持久化为 appearance，不存截图数据。

隐私画笔更新：工具栏以单个盾牌图标统一“模糊”和“马赛克”，选中后在工具条内切换两种模式。B 快捷键唤起上次选用的隐私模式。两者共用圆形连续涂抹、粗细滑块、无中心点白色光标、撤销／重做和橡皮擦；均在前景标注下方。马赛克底图在会话内缓存，使用低分辨率采样后以最近邻放大形成块状效果；预览与原像素 PNG 导出共用相同像素块。模式切换不改变已有笔画，重叠区域由后画的隐私笔画决定，擦除恢复原图。


截图选区始终为矩形。方框、圆形、椭圆属于图形标注组，进入矩形工具后在紧凑子工具栏中切换；圆形保持等宽等高，椭圆自由拖动。三者共用颜色、1.6 倍基础线宽、圆形笔宽光标、撤销／重做和局部擦除，位于模糊／马赛克上方。O / L 分别唤起圆形／椭圆标注。图钉 F 将最终截图交给独立的透明顶层窗口，约 240ms 从原选区收拢与淡入，遵循系统减少动态效果；可拖动、滚轮缩放、复制原尺寸、关闭，多图钉仅驻留内存。确认复制的默认行为保持不变。
