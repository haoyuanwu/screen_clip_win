# 定格 1.2.0

- 新增长截图：框选范围后开启，默认纵向，支持切换横向；切换方向会重置内容。
- 支持反复滚动拼接与去重、侧边缩略预览、保存和复制。
- 新增滚动速率警戒条及取景框暂停位置标记。滚动较快时优先修正对齐；参考位置移出取景框或无法可靠匹配时暂停，回到已采集区域自动恢复。
- 优化图像匹配与预览开销，连续滚动按选区尺寸刷新，停稳 300 毫秒补齐；速率条加入过渡动画。
- 修复取消长截图后无法再次截图的问题。
- 应用显示名称统一为“定格”，错误提示改为可复制的悬浮通知。
- 改善 macOS 屏幕录制授权提示，提供本机稳定开发签名配置；修复本地翻译引擎打包遗漏模块及 framework 签名结构。

## 安装

仅提供 macOS 14.0 及以上的 Apple Silicon（arm64）DMG，拖动“定格.app”到 Applications 安装。升级前请从菜单栏完全退出旧版本。

使用临时签名，尚未经过 Apple Developer ID 签名和公证。首次截图需要在系统设置中授予屏幕录制权限；如旧授权失效，按应用中的指引重新授权。本地中英翻译语言包需要在设置中另行下载。

本次未发布 Windows 或 Intel 安装包；历史 Release 附件保持不变。
