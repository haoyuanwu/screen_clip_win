# ScreenClip 设计系统

基于 UI-UX-Pro-Max 的 Flat Design、键盘可达性、显式取消、状态反馈与 Flutter LayoutBuilder 指南，针对常驻桌面截图工具调整。技能检索中的营销落地页结构不适用于本应用，未采用；品牌主色根据选区识别需求选用蓝色。

- 产品形态：无主页。常驻入口、屏幕选区覆盖层、按需偏好设置。
- 视觉层级：原屏幕内容为主角；外部遮罩约 40% 黑色，选区保持原色；工具条使用中性毛玻璃材质与细描边。
- 品牌主色：#315CEC；选区边界 #4D84FF；文字浅色模式 #222B40，深色模式 #E6EAF3。
- 浅色背景 #F5F6FA；深色背景 #141820；其余语义色由 Material ColorScheme 派生。
- 标注色：红 #D92D3E、蓝 #2459DF、绿 #168049、黑 #171B24、白 #FFFFFF。
- 隐私处理改为局部模糊笔刷；固定低于画笔、文字、箭头、方框与序号，仅对屏幕底图做模糊。
- 字体：Segoe UI，中文回退 Microsoft YaHei / PingFang SC；不依赖运行时联网字体。
- 4 / 8px 间距；10–14px 圆角；核心图标约 18–22px；保持同一 Cupertino 图标家族。
- 主操作只有“复制”，带勾号和 Enter 提示；保存为次要图标并带 tooltip。
- 选区工具条宽度随屏幕约束自适应，优先放在选区下方，空间不足时置于上方并限制在屏幕内。
- 移动与调整边界提供鼠标拖动和方向键微调。
- 所有独立图标按钮提供 tooltip；选中态同时使用底色与 selected 可访问性语义。
- 不引入持续动画；设置变化立即反馈；异步生成与复制期间禁用重复提交，显示进度。
- 配置与截屏覆盖层分离；错误保留当前选区，不把用户带到其他页面。

浅色、深色预览通过 tools/generate_preview_test.dart 使用人工生成的文档画面制作，不涉及用户截图。桌面布局检查覆盖 440、620、1024px 宽度，以及实际 200% DPI Windows 运行环境。

文字在选区内直接输入，输入框随内容和换行伸缩；点击已有文字可再次编辑，支持字号、颜色、加粗、斜体和下划线。输入文字时 Enter 换行，Ctrl / Command + Enter 完成文字；选区确认仍默认复制到剪贴板。工具栏上限宽度收窄至 480 逻辑像素，箭头和矩形线条加粗。

## 自定义工具条与图层更新

- 产品内按钮、色板、滑块、延时选项和外观选项均使用共享自定义 Flutter 控件，不使用系统菜单、Material 下拉框或样式弹窗。系统托盘、屏幕权限与文件保存对话框属于操作系统集成。
- 按 Apple HIG 的工具条分组、材质与实时反馈原则设计：中性表面、系统蓝主操作、克制阴影、16px 圆角、焦点提示、键盘可达与减少动画支持。参考 [Apple Toolbars](https://developer.apple.com/design/human-interface-guidelines/toolbars)、[Sliders](https://developer.apple.com/design/human-interface-guidelines/sliders)、[Materials](https://developer.apple.com/design/human-interface-guidelines/materials)。
- 文字编辑框与输出共享 10 源像素内边距，支持文字色、透明或实色背景、粗体、斜体、下划线和字号。字号与线条粗细采用自绘滑块；文字可点击继续编辑。
- 工具条高度按实际内容测量，在选区上下自动放置，最大高度约束内可滚动；色板在工具条内展开，不另开菜单。
- 固定图层：屏幕底图 → 局部模糊 → 自由画笔 → 文字／箭头／方框／序号。相同前景层按创建顺序绘制；模糊无论何时添加都不会抹去前景标注。
- 模糊是视觉处理，不等同于彻底删除敏感信息；不宣称可保证信息无法推断。
- 本次通过 UI-UX-Pro-Max 技能与 Apple HIG 完成界面设计。Product Design 已连接，本次依其框架做桌面组件复核；结果及证据限制见 docs/product-design-review.md。

紧凑交互更新：工具栏宽度从 640 缩至 480 逻辑像素，上下内边距压缩为 4–6px，头部提示与操作合并收紧；字号滑块与字形选项同排，色板仅在需要时展开。按钮支持约 110ms 的按压缩放回弹、100ms 的悬停／选中底色过渡，设置页切换约 170ms，工具状态与色板展开淡入并自动调整高度，工具条约 140ms 入场，位置采用同帧边界约束。屏幕底图本身不参与页面切换动画。遵循系统减少动态效果设置；减少动画时状态直接切换。

毛玻璃与笔刷反馈：浮层使用 24px 背景模糊，浅色 72%、深色 70% 的中性半透明底色（高对比度模式恢复实色）。自由画笔、箭头、矩形、模糊画笔和序号工具在选区内以同色圆圈表示当前宽度，源像素映射到显示坐标；模糊光标直径对应实际涂抹范围。工具条粗细滑块旁有同色圆圈预览，大笔刷在工具条内缩小显示并保留实际像素数值。圆圈只属于编辑反馈，不进入导出；离开选区、进入工具条或编辑文字时隐藏。


四边定位更新：原生层返回每块显示器在截图中的实际像素边界；工具栏选择与选区重叠面积最大的单块显示器，不使用整片虚拟桌面作为安全区域。每次布局直接测量当下内容尺寸，依次寻找选区下、上、右、左的可用位置；放不下时覆盖选区的一部分，但保持尺寸并约束在当前显示器内。选区靠边仅重新定位，宽高约束与距离屏幕边缘无关。取消了可能跨越屏幕边界的位置补间动画，保留面板内容与按钮动画。自动化检查覆盖两块屏幕各四角、文字与色板展开的中间帧，以及竖屏和上下错位显示器布局。

主题提供“跟随系统 / 浅色 / 深色”三种选择。新安装默认跟随系统，系统明暗变化即时生效；已有用户的手动明暗选择继续保留。主题偏好持久化为 appearance，不存截图数据。

隐私画笔更新：工具栏以单个盾牌图标统一“模糊”和“马赛克”，选中后在工具条内切换两种模式。B 快捷键唤起上次选用的隐私模式。两者共用圆形连续涂抹、粗细滑块、无中心点白色光标、撤销／重做；均在前景标注下方。马赛克底图在会话内缓存，使用低分辨率采样后以最近邻放大形成块状效果；预览与原像素 PNG 导出共用相同像素块。模式切换不改变已有笔画，重叠区域由后画的隐私笔画决定。


截图选区始终为矩形。方框、圆形、椭圆属于图形标注组，进入矩形工具后在紧凑子工具栏中切换；圆形保持等宽等高，椭圆自由拖动。三者共用颜色、1.6 倍基础线宽、圆形笔宽光标、撤销／重做，位于模糊／马赛克上方。O / L 分别唤起圆形／椭圆标注。图钉 F 将最终截图交给独立的透明顶层窗口，约 240ms 从原选区收拢与淡入，遵循系统减少动态效果；可拖动、滚轮缩放、复制原尺寸、关闭，多图钉仅驻留内存。确认复制的默认行为保持不变。

智能备选：区域截图和窗口截图沿用系统窗口前后顺序，预览鼠标下最上层窗口的矩形范围。备选框内显示原图，框外保留 40% 黑色遮罩；预览时隐藏放大镜。点击采用备选，区域截图仍支持拖动自由框选。依据 UI-UX-Pro-Max 的短反馈、可打断动画与 Flutter 隐式动画建议，备选切换提供 120ms 外侧描边淡出，选区确认提供 180ms 外侧描边淡出，使用 easeOutCubic。反馈独立绘制并隔离重绘，始终不覆盖框内内容；边界与拖动即时更新，快速切换立即替换旧反馈，减少动态效果时省略动画。

文字交互：编辑时点击文字框外围仅提交当前文字，同一次点击不会新建文字。文字或选择工具下，悬停已有文字显示八个大小调整手柄和顶部圆形旋转手柄；拖动内部移动，单击内部重新编辑。普通拖动手柄调整框宽高，字号保持不变，内容按框宽换行并裁剪在框内；Shift 拖动四角围绕对角等比例缩放文字、内边距和框。旋转后命中、手柄光标、再次编辑和 PNG 导出使用相同几何变换。单次拖动计作一次撤销操作，取消拖动恢复原状。

透明毛玻璃更新：截图编辑工具栏保留 24px 背景模糊，浅色底色不透明度降至 40%，深色降至 32%，使用轻薄半透明描边；高对比度模式仍使用实色。图钉图片填满窗口，标题栏浮在图片内部顶部，不额外占用图片高度；默认隐藏，鼠标进入整张图片后 160ms 渐显，离开后 100ms 淡出，快速移入移出可打断，减少动态效果时立即切换。macOS 使用窗口内 NSVisualEffectView，Windows 使用图片顶部的缓存模糊采样与半透明深色底。复制和导出始终只包含原始图片。

智能选取补充：窗口之外的区域以当前截图的完整桌面边界作为备选，框内保持原图。Windows 点击窗口后临时置顶并重新取图，完成或取消后恢复。macOS 通过 ScreenCaptureKit 的 desktopIndependentWindow 独立抓取窗口内容，按原始选区坐标合成到桌面快照，不改变真实窗口层级；改选桌面恢复最初快照。无需辅助功能权限，删除相关申请、弹窗、偏好项与状态回显，仅保留截图所需的屏幕录制权限。抓窗失败保留当前截图及可操作的错误说明；保存取消或复制失败仍保留截图会话。

文字对齐：文字工具栏以同组图标提供左对齐、居中和右对齐，当前模式使用共享按钮的选中反馈与可访问性语义。编辑中的文字实时预览；选中但未编辑的文字可直接应用，对齐改变支持撤销／重做，移动、旋转和缩放保留对齐属性。自动文字框至少保留 80 源像素的内容宽度（受可用宽度限制），固定文字框按其完整内宽对齐；输入框与 PNG 导出共享字号、内边距和布局宽度，多行文字按同一规则排列。


直线标注：新增独立直线工具与 S 快捷键，点击起点后显示端点标记，随鼠标即时预览，点击终点或按 Enter 完成；也可按住拖动绘制。每条线只保存两个端点，无箭头，共享箭头的 1.6 倍基础线宽、颜色、笔宽圆圈和前景图层，支持一次撤销／重做。待完成的直线可用 Esc 或撤销取消，切换工具、重新框选及指针取消时清除预览；终点未确定时禁用复制、保存和图钉，避免预览进入导出。

文字背景绑定：选中但未编辑的文字框修改背景时，直接写回该对象并记录一次可撤销的文字修改；编辑中的文字仍实时更新草稿，未选中文字时设置后续新建文字的默认背景。按钮色样和色板选中态读取当前对象的实际背景，包含透明色；撤销／重做后同步恢复，保留位置、尺寸、旋转与对齐，预览和 PNG 导出一致。

形状文字气泡：完成箭头、直线、矩形、圆形或椭圆后，在可见形状右下角显示蓝色“添加文字”气泡；包含箭头头部的实际范围，并在当前显示器内避让工具栏。默认 5 秒后淡出，悬停或键盘聚焦时暂停，离开后再保留 2 秒。点击后在形状附近新建独立文字框，不误打开已有文字；继续绘制、切换工具、撤销、重新框选或确认截图时隐藏。气泡只属于编辑反馈，不进入截图导出，支持减少动态效果。

方框误触与工具栏自适应：矩形、圆形和椭圆只提交宽高均达到 8 逻辑像素的拖动结果，单击与过小形状不增加标注或撤销记录，也不清空重做。工具栏取消固定 480px 宽度，按实际工具、文字编辑控件和间距测量自然宽度；受当前显示器安全边界限制，空间不足时换行、必要时纵向滚动。宽度与选区靠边距离无关。滑块使用可测量的固有尺寸，按实际显示宽度响应拖动；状态提示在窄屏或大字号时可截断，避免挤出操作按钮。

空文字自动清理：完成文字编辑时，空内容或只有空白字符的文字框自动移除，背景颜色不例外；新建空框不生成标注或撤销记录。已有文字被清空后以一次可撤销的对象删除提交，恢复原内容、样式、位置与变换，并保留其他文字的编辑索引。Esc 取消编辑仍恢复编辑前的文字。

隐私交互：默认画笔，可切换框选；模糊与马赛克共用此选择。框选拖动实时预览，松开提交，点击与小于 8 显示像素的区域不创建记录。框选使用精准光标并隐藏笔刷粗细控件，保留撤销／重做与原有图层规则。


OCR：在截图工具栏提供“识别文字”入口，仅识别当前选区的合成画面，包含隐私处理与前景标注。识别期间在选区内显示暖白柔光扫描，工具栏显示本机处理状态，禁用冲突操作并保留取消识别入口；减少动画设置下仅显示轻微暖色静态提示与工具栏状态，不循环移动。完成后直接在原图文字上按住拖动选择，按字符高亮并支持跨行、反向选择、全选、Ctrl/⌘+C 和工具栏复制。字符坐标不可用时按词框与字形宽度细分，macOS 优先采用 Vision 字符框。不重绘或遮挡原字，扫描与选中高亮均不进入导出。Esc 或切换工具退出识别，退出后继续标注。结果仅保存在内存，不自动写入剪贴板或保存；空结果和识别失败提供清晰反馈。

工具栏分组：主工具行按“常用标注（选区、箭头、矩形、画笔、文字）｜补充标注（直线、序号）｜隐私与识别（隐私画笔、OCR）｜样式与撤销（颜色、撤销、重做）｜输出操作（取消、保存、图钉、复制）”排列，组间使用细竖线和额外留白。同组按钮保持连续，窄窗口按组换行，避免分隔线单独换行。

光标微调：截图时 W/A/S/D 分别上/左/下/右移动真实系统光标，每步一个截图源像素，HiDPI 按截图比例换算。鼠标按住时同步更新选区、绘制与文字移动/缩放/旋转手势；Shift 仍用于文字等比例缩放，Shift+WASD 也逐像素移动。一次手势只生成一步撤销。文字编辑与 OCR 结果输入不拦截这些字母。箭头快捷键改为 Q，直线改为 G，避免与微调冲突；Ctrl/⌘+A、Ctrl/⌘+S 保持原用途。

OCR 全流程反馈（UI-UX-pro-max）：点击后工具栏立即进入识别状态；选区使用暖白柔光扫描，不加 OCR 外框、不覆盖黑色提示块。允许取消，丢弃取消请求的迟到结果。成功后以浅金色荧光笔填充全部可复制文字区域，不描边，约 210ms 渐显、560ms 停留、630ms 淡出，只播放一次；开始拖选即停止提示。选中文字使用半透明青绿色，与识别提示区分，保留原字清晰度。工具栏统一轻量状态卡：识别中、找到行数、已选字数、复制中、复制成功/失败；复制成功同时显示勾选图标。空结果与失败提供重试、返回标注，重新框选使用主工具栏现有入口。减少动画时使用短暂静态提示。所有效果仅存在于预览，不进入导出。

二维码扫描：与 OCR 同属图像工具，使用 flutter_zxing ^3.1.0 在后台处理当前选区的 RGBA 数据，不联网或落盘。多个二维码各自保留空间位置，即使内容相同也分别显示中心彩色背景箭头按钮。链接点击后打开 http/https 网页并退出截图会话，不导出图片或改动剪贴板；恢复窗口层级时不抢回浏览器焦点；文本二维码显示可选择复制的内容。右键按钮可查看链接文本，识别空结果或失败均可重试。所有按钮不进入导出。

取色：全局 Ctrl+Shift+C 绕过区域框选和截图延时，截图工具栏 I 进入取色。以屏幕截图源像素读取 8-bit sRGB，实时显示色块、HEX、rgb(r,g,b)；预览跟随鼠标并避让显示器边缘。点击后固定位置，数值按钮逐项复制并显示成功或失败反馈；全局模式退出全屏并呈现 300×320 悬浮卡片，截图内模式保留编辑状态。WASD 可继续逐像素取色。主界面和系统托盘均提供入口，设置页显示快捷键注册状态。

文字编辑尺寸：为插入光标单独预留 3 显示像素，保持 EditableText 与导出 TextPainter 的换行一致。输入时自然增宽，抵达选区右缘后换行增高；靠近底边向上展开，关闭内部滚动与滚动留白。重新编辑已有文字框时保留手动尺寸作为起始尺寸，内容不足时自动扩展。

取色放大预览：实时显示以采样像素为中心的 17×17 像素区块，按最近邻方式放大，黑白双线框标出中心像素；边缘位置采用夹取像素，避免偏移或越界。点击固定时保存独立的小区块，固定颜色卡片继续显示该放大图，无需保留整张屏幕像素。放大图与色值共用同一 sRGB 缓冲，WASD 变化同步刷新。

macOS Retina 光标微调修正：原生层保留截图源像素的精确目标坐标，并记录系统实际光标位置。连续按键从精确目标累加，避免半个系统坐标单位被取整后向右/向下停在原位；真实鼠标移动后重新设定起点。每次截图重置累加器，移动失败也重置。

图钉 OCR：原生图钉显示后通过独立 ID 通知 Flutter，后台调用同一 desktop_vision OCR 并将归一化字符框回传；多个图钉的结果分离，已关闭图钉忽略迟到结果。识别完成短暂浅金填充，鼠标命中文字使用 I-beam，拖动选中、反向跨行、Ctrl/⌘+C 复制、Ctrl/⌘+A 全选。顶部增加文字复制按钮，无选中时复制全文；原图片复制按钮仍只复制图片。文字选区青绿高亮不写入 PNG，开始选字后抑制图钉移动；空白区域继续移动，Option/Alt 可强制从文字区域移动。识别失败或无字显示状态，不关闭图钉、不自动改动剪贴板。
