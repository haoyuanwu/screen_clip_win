# 翻译交互

依据用户的《Flutter 多渠道翻译模块设计文档》实现，使用 UI/UX Pro Max 的桌面工具、Flutter 表单验证、异步反馈建议；检索结果中的营销页面结构不适用于常驻截图工具，没有采用。沿用 MASTER 中的系统蓝、中性表面、系统字体及 4/8px 间距，不引入网络字体。

## 入口与工作流

- 常驻工具条提供“文字翻译”；偏好设置顶部提供独立的“翻译 API Key”卡片，点击“配置”直达渠道设置，关闭配置后返回偏好设置。不新增首页或历史列表。
- 截图工具栏提供“翻译选区文字”，复用 OCR 的扫描光效与状态提示；优先翻译已选择的 OCR 文字，否则本地识别整个选区。按 OCR 行保留位置，将所有文字区域合并为一次 JSON 数组请求，并校验响应区域数量。
- 完成后把译文放回对应图像区域，使用不透明浅米色背景与深色文字；按区域自适应换行和字号，形成普通可编辑文字标注，可移动、缩放、随截图导出和一次撤销。
- 独立文字翻译仍使用面板；截图中点击翻译按钮直接开始。未配置/未启用当前渠道或安全存储读取失败时，直接打开配置页；配置好返回后继续。仅主动翻译发送文字，OCR 不触发翻译请求、不上传图片。
- 截图中的面板限定在当前选区所属显示器内，使用 160ms easeOutCubic 淡入与 0.99→1 的轻微缩放；系统减少动画时直接呈现。面板使用同一编辑层同步到原生多屏覆盖层，不改变原选区或标注。
- 配置面板关闭后继续原截图；翻译中可取消，失败保留原标注并提供重试及配置入口，取消后的迟到响应不添加标注。打开获取 Key 网站时保留截图会话，返回应用恢复覆盖层。

## 布局与反馈

- 宽度 ≥620px：原文与译文等宽并排；窄窗口上下排列，区域等宽。保持操作区与状态区位置稳定。
- 顶部仅保留语言、交换和渠道三个控制组；自定义选择展开为有边界的可滚动选项区，避开系统下拉菜单跨屏定位问题。
- 无 Key 时显示内联配置入口。配置页留在同一面板中；表单具备可见标签、提交验证、字段内错误、保存失败保留输入。
- OCR 提取、翻译等待、完成、取消、失败分别提供文字反馈；加载时显示轻量进度并保留取消按钮。减少动画时保留状态文案，停止循环动画。
- 原文可编辑，译文可选择；复制提供成功/失败反馈。新请求或源文字变更会使旧的复制反馈失效。
- 请求取消、关闭、原文修改或渠道/语言修改后，迟到响应不会覆盖新状态。无自动付费重试。

## 渠道与隐私

- 预置智谱 AI、DeepSeek、通义千问、Kimi、豆包、OpenAI；支持自定义兼容接口、模型、Key、启停和当前渠道切换。
- API Key 与渠道配置一起存入 flutter_secure_storage，不写入 preferences.json，不输出至日志。界面只显示 Key 末四位；编辑已有 Key 时字段为空，留空保留原 Key，显式清除或删除才移除。
- macOS 使用非共享的传统钥匙串，避免临时签名 DMG 因 Keychain Sharing 额外依赖分发描述文件；Windows 使用插件提供的安全存储。实际存储失败必须可见，不能静默回退明文。
- 仅保存渠道与语言偏好，原文、译文和 OCR 结果不写入磁盘。
- 自定义地址要求 HTTPS，本机 localhost/127.0.0.1/::1 可用 HTTP；鉴权失败、额度/频率限制、超时、不兼容返回、空结果及截断均有可操作说明，不展示包含密钥的服务器原始响应。

## 图上译文与对照阅读

- 翻译完成的状态条增加“对照阅读”选中按钮。默认仍为图上译文；开启后按稳定段落 ID 暂时隐藏本次译文标注，选框旁显示可滚动、可选择与复制的译文窗口；关闭、再次点击按钮或 Esc 恢复图上标注，不重新调用 OCR/API。
- OCR 文字段的原始坐标与译文保持一一对应。鼠标悬停或点击原文文字段，窗口自动定位对应译文；两处使用同一暖米色作背景对照，译文同时显示段号和“正在对照”，避免仅靠颜色传达状态。鼠标移入译文窗口时保留最后的原文高亮。
- 支持上一段/下一段按钮、键盘上下键以及复制全部译文，长文本可选择局部复制。定位滚动和窗口进入采用 140–160ms 缓动；减少动画或 macOS 后台镜像状态直接定位，确保多屏可见。
- 窗口优先放在选区左右，避开工具栏，约束在当前显示器的安全范围内；空间不足时在屏幕内放置。窄窗口、160% 字号、深浅主题均验证。
- 译文标注的编辑、移动、缩放保留段落 ID，原文定位框仍对应原始 OCR 位置。撤销/重做按实际存在的标注控制对照入口与内容；隐藏是显示模式切换，不添加撤销记录。对照窗口与高亮不写入截图；对照模式下截图导出使用隐藏译文后的标注层。


## 对比度、二级菜单与配置续接

- 截图工具栏保留毛玻璃，浅色遮盖度 92%、深色 90%，避免截图内容透过底色干扰图标。紧凑图标统一 18px；选中按钮使用实色主题容器、对比前景与描边，悬停/按压反馈不改变布局。深浅主题均检查普通与选中前景对比度 ≥4.5:1。
- 二级菜单使用独立的浅层面板与 8px 内边距；文字按字号/样式/对齐分组，形状选项与线宽分行，隐私工具按处理效果/操作方式分组，颜色面板将标题放在色块上方。标签和控制组整体换行，避免标签单独掉行；窄屏与大字号继续限制在当前显示器内。
- 对照窗口与选框间距固定为 8px，按左右可用空间自动选择；左侧定位使用选框左缘，不能锚定屏幕左缘。左右不足时尝试上下，并以遮挡面积、工具栏遮挡及距离综合选位，不固定在某一侧。
- Key 编辑页提供“验证 API Key”，使用当前未保存输入或已保存 Key 向当前地址、模型发送一条 Hello 测试（max_tokens=64）。验证不保存配置、不上传截图、不修改当前翻译结果；支持取消，输入变化立即使旧验证失效，错误不展示原始服务器响应。
- 截图内的配置仍是原编辑器上的面板，保持 capture 状态、选区和已有标注。截图配置页显示“保存并继续截图”，保存成功关闭配置并继续原翻译操作；独立设置页保持“保存渠道”与返回设置的导航。


## 对照窗口拖动与小选区

- 对照窗口绘制在工具栏上方并优先接收鼠标；打开时测量工具栏实际位置，参与自动避让。无足够空位时允许窗口与工具栏重叠，窗口标题、复制与关闭仍可操作。
- 标题区域支持拖动，光标为抓取样式，提供文字提示。移动以编辑器逻辑坐标处理并约束在所属屏幕安全范围内；段落定位和工具栏尺寸变化不会重置手动位置。新一轮翻译重置为自动定位。
- 选区显示宽度小于 300px、高度小于 160px，或拟合后的任一译文字号低于 12px 时，翻译完成自动进入对照阅读。判断使用逻辑显示尺寸，适应 Retina 缩放；用户仍可关闭或点击工具栏按钮切回图上译文。


## 主工具栏展开锚点

- 按二级菜单及颜色面板的预估展开高度提前选择停靠方向，宽屏预留 240px、窄屏预留 320px，并响应系统字号与屏幕高度限制。停靠方向只在选区或所属屏幕变化时重新选择，不随每一帧菜单动画重新选边。
- 上方停靠时，二级面板和色板排列在主工具栏上方，保持主工具栏的下锚点；下方停靠时保持主工具栏的上锚点。全屏或屏幕边缘无外部空间时使用屏内锚点，展开和收起不跨到选区另一侧。
- 验证包含菜单动画中间帧、文字菜单及背景色板的连续开关、窄屏、大字号和多屏约束。

- 工具栏顶部尺寸与三横线区域支持拖动移动；保持主工具与菜单锚点，移动不影响选区或标注。位置限制在当前显示器安全区域，重新框选后恢复自动定位。
